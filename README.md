# JourneyQuest VR: Greater Manchester

A five-minute immersive public-transport confidence experience for pupils aged 8–13, created by Neptune’s Submerge.

Open the published site in Meta Quest Browser and select **Enter VR**.

Prototype content:
- Journey planning
- Bus-stop safety
- Tram disruption
- Manchester Airport navigation
- Help-seeking
- Teacher summary

This is a demonstration prototype and is not an official TfGM or Manchester Airport product.
